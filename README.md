# IRONFORGE Gym Landing Page

Pure HTML5 + CSS3 + vanilla JavaScript. No React, Python, build tools, or framework required.

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Included
- Sticky responsive navigation + mobile hamburger
- Smooth scrolling and active navigation highlighting
- Hero CTA and stats
- About / training feature sections
- Six training/service cards
- Responsive membership pricing with featured plan
- Testimonial slider with controls + autoplay
- FAQ accordion
- Contact/trial form with client-side validation and success state
- Embedded Google Maps location
- Responsive layouts for desktop/tablet/mobile
- Scroll reveal animations

## Customization
Edit the content, prices and contact information in `index.html`. Change visual variables at the top of `styles.css`. Replace the demo form handler in `script.js` with your backend/API when ready.
